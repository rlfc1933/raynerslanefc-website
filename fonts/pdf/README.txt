Manrope-Regular.ttf — a static TrueType copy of the site's own Manrope
(fonts/manrope-latin.woff2, variable, instanced at wght 400 with fontTools).

Used only by js/programme-export.js to write the invisible, selectable text
layer of the programme PDF (jsPDF cannot embed WOFF2 or variable fonts).
The visible page is the rendered page image; this font makes its words
searchable and copyable with correct Unicode.

Licensed under the SIL Open Font License 1.1 — see OFL-Manrope.txt.
Instancing a variable font is a modification under the OFL. The licence
declares no Reserved Font Name, so the original name is kept.
