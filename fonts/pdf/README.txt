Static TrueType copies of the site's own fonts, for embedding in Programme
Studio PDFs (jsPDF cannot embed WOFF2 or variable fonts).

Made from fonts/manrope-latin.woff2 (variable, instanced at wght 400/600/800)
and fonts/bebas-neue-latin.woff2 with fontTools. Both fonts are licensed under
the SIL Open Font License 1.1 — see OFL-Manrope.txt and OFL-BebasNeue.txt.
Instancing a variable font is a modification under the OFL. Neither font's
licence declares a Reserved Font Name, so the original names are kept.
